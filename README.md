One Emoji, One Dream Vacation: **🏖️**

One emoji, one dream vacation: **🏖️** — a beach with an umbrella, the postcard at a glance. The other candidates — the desert island 🏝️ and Mount Fuji 🗻 — are kept in `vA/`, `vB/`, `vC/`; vA was chosen because it is just as evocative and far rarer in the field (2 copies vs 69 for the island).

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 26.13.1 per the kit).
The program writes exactly the entry above to `/output/entry.txt` — no
trailing newline, so the file holds exactly the entry — and prints exactly
that text to stdout. It uses no network, no randomness, no clock and no
environment input, so two runs produce byte-identical output.
